# deposit_service

# Описание проекта

REST API сервис расчета депозита на Django. 
Приложение разработано с использованием современных технологий,
таких как Poetry для управления зависимостями и Docker для контейнеризации.

# Стэк технологий

- **Django+DRF**: Веб-фреймворк для создания веб-приложений.
- **Poetry**: Инструмент для управления зависимостями и упаковки Python-проектов.
- **Docker**: Платформа для создания, развертывания и запуска приложений в контейнерах.
- **Docker Compose**: Инструмент для определения и запуска многоконтейнерных Docker-приложений.

# Требования

Перед началом работы убедитесь, что на вашем компьютере установлены следующие инструменты:

    Docker
    Docker Compose
    Poetry

# Установка проекта

## Шаг 1: Клонирование репозитория

    git@github.com:anzhkashina/deposit_service.git    
    cd deposit_service

## Шаг 2: Установка зависимостей
Убедитесь, что у вас установлен Poetry, и выполните команду:
    
    poetry install

Эта команда установит все зависимости, указанные в файле pyproject.toml, и создаст виртуальное окружение.

## Шаг 3: Запуск Docker Compose
Проект использует Docker Compose для запуска контейнеров с Django и PostgreSQL.
Чтобы запустить контейнеры, выполните команду:

    docker-compose up --build

Команда соберет Docker-образы и запустит контейнеры.

## Шаг 4: Применение миграций
После того как контейнеры будут запущены, выполните миграции базы данных:

    docker-compose exec web python manage.py migrate

## Шаг 6: Доступ к проекту

Теперь проект доступен по адресу http://0.0.0.0:8000/api/deposits/
